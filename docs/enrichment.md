# Enrichment — paper cards

🇷🇺 [Русская версия](enrichment.ru.md)

Enrichment produces a **paper card** — `summary_en`, `summary_ru`, and `tags` — for display in
Telegram. It is deliberately **decoupled from indexing**: it reads existing rows and writes only the
card fields, never `ingest_status`.

## Inputs

`get_enrichment_input` ([papers.py](../app/db/papers.py)) builds the model input from the DB:
`title`, `abstract`, and a small set of **excerpts** — the first two chunks plus the last chunk
(ordered by `chunk_index`, deduped). It does not re-read the PDF.

## Generation

`enrich_paper_card` ([enrich.py](../app/rag/enrich.py)) calls Gemini (`gemini-flash-latest`,
temperature 0.2, `response_mime_type=application/json`, 3 retries with backoff). The prompt asks for
factual `summary_en` (2–4 sentences), `summary_ru`, and 3–8 short English `tags`, with no invented
results. The response is JSON-parsed and validated: both summaries must be non-empty and `tags` must
be a list, otherwise it retries / raises.

## Persistence

`save_paper_enrichment` writes `summary_en`, `summary_ru`, `tags` and bumps `updated_at`. It **does
not touch `ingest_status`** — so enrichment can succeed or fail independently of whether the paper is
indexed.

## Triggers and failure isolation

- **Automatic** — a successful `ingest_paper` / `/reindex` immediately runs `enrich_and_save`. If
  enrichment fails, the bot still reports the paper as indexed (`"indexed ok; enrich failed: …"`),
  and the paper stays searchable.
- **Manual** — `/enrich <arxiv_id>` regenerates the card for any paper already in the DB
  (`get_paper_status` must not be `None`); on failure it reports and leaves `ingest_status`
  unchanged.

## Not yet used in retrieval

The card is stored (and `tags` has a GIN index), but **retrieval does not use it today** —
`hybrid_search` ranks chunks, not summaries or tags, and `/ask` / `/list` never filter by `tags`.
Enrichment currently serves the human-facing card only. Wiring tags/summaries into retrieval is a
possible future step, not a wired one.
